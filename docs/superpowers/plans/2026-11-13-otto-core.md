# ES5506 OTTO Core (Plan 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An instantiable, integer-only C++17 core of the Ensoniq ES5506 "OTTO" written from its datasheet: the byte-latched host interface and paging, address generation and all loop modes, compressed samples, interpolation, the 4-pole filter, hardware envelopes, volume/pan, the 6 stereo channels, interrupts and the pot A/D, each with rule tests.

**Architecture:** One class `ens::Otto` in `src/otto/` with pure signal-path helpers exposed for testing, the same shape as the KS-32 OTIS core (`KS/src/otis/otis.h`, read as a guide only; OTTO is written fresh). Sound memory is an abstract `OttoMemory` the TS machine (Plan 3) implements. One `stepVoice()` per voice slot; a frame is ready after slot ACTV.

**Tech Stack:** C++17, CMake, the `tests/check.h` registry. MinGW-w64 i686 + Ninja and MSVC x64, as Plan 1.

**Spec:** `docs/design/2026-11-13-ts-emulator-design.md` (section 11 item 2) and the datasheet notes `docs/reference/es5506-otto-datasheet-notes.md` (cited below as "notes §N"; they cite the PDF `datasheets/ES5506 OTTO Specification Rev 2.3.pdf`).

**Branch:** `plan2-otto` from `main`; merged into `main` with a merge commit at the end.

## Global Constraints

- C++17; warnings clean at `/W4` and `-Wall -Wextra`; no float or double in `src/otto`; no OS calls, file I/O, threads or mutable statics in `src/`.
- Output must be bit-identical between the MSVC x64 and MinGW i686 builds.
- The datasheet is the reference. MAME is never consulted to write or check this core.
- Every behaviour the datasheet leaves open is a `// DECISION OT<n>: <one line>` at the point of use plus an `## OT<n>: <title>` entry in `docs/decisions.md` under `## OTTO` (template at the top of that file). The defaults below are the entries' Choice; Evidence cites the notes section.
- New test files are added to `ENS_TEST_SOURCES` in `tests/CMakeLists.txt`; the library is `ens_otto` (`add_library(ens_otto STATIC src/otto/otto.cpp)`, linked to `ens_common`) and `ens_tests` links it.
- The Plan 1 suite (194 tests) keeps passing.

## Decision Defaults

Units: `S` = 2048 (one sample in ACCUM units); `START32 = START & 0xFFFFF800`, `END32 = END & 0xFFFFFF80`; ACCUM, START and END share one 32-bit layout (notes §2), so they compare directly. Filter values are 18-bit signed integers in half-LSB units (one fraction bit, FDF0).

| Id | Topic | Default | Evidence / confidence |
|---|---|---|---|
| OT1 | Host byte latching | `write(ha, d)`: reg = `ha >> 2`, byte = `ha & 3` (0 = MSB). Bytes 0-2 go into one write latch shared by all registers; a byte-3 write commits `latch0<<24 \| latch1<<16 \| latch2<<8 \| d` to the register at that address on the current page. `read(ha)` byte 0 reads the 32-bit register into one shared read latch (with the read's side effects, OT14/OT16) and returns bits 31:24; bytes 1-3 return the latch. Latches are 0 after reset and keep their bytes after a commit. | Notes §1. Shared latches not stated. Medium. |
| OT2 | Pages and unused bits | PAGE keeps 7 bits. TEST (bit 6) = 1 selects the test page whatever PS is. Writes keep only each register's implemented bits (mask table in Task 1); reads return them with other bits 0. Page-40 reads and EMPTY return 0. Filter temps read back their 18 bits, not sign-extended. | Notes §1, §2, §9.11, §9.15. Low-medium. |
| OT3 | Reset state | ACTV 0x1F, MODE 0x17, PAGE 0, IRQV 0x80 (free, vector 0), PAR 0, W_ST/W_END/LR_END 0. Every voice: CR 0x0003 (STOP1\|STOP0), all other voice registers and filter temps 0, FILTCOUNT 0. Channel sums and test values 0. | Notes §8; the rest by analogy with KS-32 O10. Low. |
| OT4 | Address and loops | Only when CR.STOP0 = CR.STOP1 = 0. DIR=0: `n = acc + FC`; boundary when `n > END32` (strict). DIR=1: `n = acc - FC`; boundary when `n < START32`. Computed in 64-bit, stored mod 2^32. At a boundary, unless LEI=1: BLE=0,LPE=0: set STOP0, `acc = END32` (fwd) / `START32` (rev). BLE=0,LPE=1: `acc = START32 + (n - END32)` (fwd) / `END32 - (START32 - n)` (rev). BLE=1,LPE=1: `acc = END32 - (n - END32)` (fwd) / `START32 + (START32 - n)` (rev), toggle DIR. BLE=1,LPE=0 (transwave): as BLE=0,LPE=1, then clear BLE and set LEI. LEI=1: `acc = n`, no boundary, no IRQ. FC is added once. DIR=0 is forward. | Notes §3, §9.2-9.4 (§4.1.5 text over the BM print; the p29 strict-compare note over step 5). Medium. |
| OT5 | Fetch addresses | S1 at `acc >> 11`, S2 at `((acc >> 11) + 1) & 0x1FFFFF` in both directions, bank = CR.BS1:BS0. Fetched with the accumulator before this slot's update. | Notes §3 steps 1-2. Medium. |
| OT6 | Compressed samples | CMPD=1: `otto_decompress(word)`: `e = word >> 13`, `m = word & 0x1FFF`; `e >= 1`: `v = (int16)(((m >> 12 ^ 1) << 15) \| (m << 2)) >> (7 - e)`; `e == 0`: `v = (int16)(m << 3) >> 7`. | Notes §3 (encoder and p31 examples; decoder inferred). Medium. |
| OT7 | Stopped voice | STOP0 or STOP1: the address ALU, IRQ check and envelopes are frozen and the voice adds 0 to its channel; it still fetches, interpolates and runs the filter (the filter temps keep updating). | §4.6/§4.8 force volume 0. Fetch and filtering on a stopped voice are unstated (§9.6); kept as the KS-32 OTIS did, whose firmware relied on it (KS-32 O7). Plan 3 revisits with the TS firmware. Low. |
| OT8 | Interpolation | `otto_interp(s1, s2, f9) = (s1 << 1) + (((s2 - s1) * f9) >> 8)` (floor), `f9 = (acc >> 2) & 0x1FF` (fraction bits F10..F2). Result in half-LSB units. | Notes §3, §9.5. Medium. |
| OT9 | Filter arithmetic | `k12 = K >> 4`. `otto_lp(x, y1, k12) = sat18(y1 + ((k12 * (x - y1)) >> 12))`. `otto_hp(x, x1, y1, k12) = sat18(x - x1 + (((k12 + 2048) * y1) >> 12))` (the datasheet's +0.5). sat18 clamps to [-131072, 131071]. | Notes §3, §9.7. LP medium; HP scale low (above K = 0x7FF0 the gain exceeds 1). |
| OT10 | Filter routing | Pole 1: LP K1 on x, state O1(n-1). Pole 2: LP K1 on O1, state O2(n-1), O2(n-2) keeps pole 2's previous output. Pole 3 by the p9 table (00 HP K2, 01 LP K1, 10 LP K2, 11 LP K1); HP uses Xn-1 = O2(n-2). State O3(n-1), O3(n-2) keeps pole 3's previous output. Pole 4: LP4=1 LP K2, LP4=0 HP K2 with Xn-1 = O3(n-2); state O4(n-1). | Notes §3: the p9 table matches the ES5505 table; the p34 drawing disagrees in modes 10/11. Medium. |
| OT11 | Filter to pan | `x16 = sat16(O4 >> 1)` (drop the fraction bit). | Notes §3, §9.7. Medium. |
| OT12 | Volume | `otto_vol(x16, vol) = ((x16 * (0x100 \| ((vol >> 4) & 0xFF))) >> 5) >> (15 - (vol >> 12))`, arithmetic shifts. Exponent 0 is a shift of 15, not a mute. | Notes §3. Medium. |
| OT13 | Channels | CA 0-5 adds L/R into that channel's sums; CA 6/7 add nothing. Sums are kept in 32 bits (no 23-bit wrap). At the frame end each sum is saturated to 20 bits ([-524288, 524287]) into the frame and cleared. With PAGE.TEST=1 the frame latches the host-written CH values (23-bit, sign-extended, saturated to 20 bits) and voice sums are discarded. | Notes §3, §9.10, §9.15. Saturating sums: low (a reasonable listener expects clipping, not wrap noise). |
| OT14 | IRQ and IRQV | On a boundary with IRQE (OT4), set CR.IRQ. At each slot, if that voice's CR.IRQ is set and IRQV is free (bit 7 = 1) and the voice is not awaiting its clear, latch IRQV = voice (bit 7 = 0) and assert the pin. A byte-0 read of IRQV returns the value then sets bit 7 and releases the pin, and marks that voice; at its next slot its CR.IRQ is cleared. A host write of CR with IRQE\|IRQ forces a request. IRQV reads: bits 4:0 vector, bit 7, others 0. | Notes §5. Medium. |
| OT15 | Envelopes | Per voice, after the signal path, only when not stopped: if ECOUNT ≠ 0: `LVOL = otto_ramp(LVOL, LVRAMP>>8)`, same for RVOL; if K1RAMP bit 0 (SLOW) = 0 or FILTCOUNT = 0: K1 ramps; K2 likewise with K2RAMP's own SLOW bit; ECOUNT -= 1. Then FILTCOUNT = (FILTCOUNT + 1) & 7 (per voice; counts on stopped voices too). `otto_ramp(v, r8) = clamp(v + (int8)r8, 0, 0xFFFF)`: the ramp adds at the register's LSB (the fine bits). | Notes §3, §9.8. Medium-low. |
| OT16 | Pot A/D | `setPot(v10)` sets the pin's value. A byte-0 read of PAR returns PAR, then sets PAR = 0x3FF and starts a conversion; 512 slots later PAR = the pot value at that moment. | Notes §6 (512 µs = 512 slots at 16 CLK/slot; clock-independent in slots). Medium. |
| OT17 | Write timing | Host writes take effect at once; the datasheet's 3-voice pipeline that can overwrite CPU writes is not modelled. | Notes §4. Medium (the firmware writes twice anyway). |
| OT18 | Serial and MODE | MODE, W_ST, W_END and LR_END are stored and read back; output is modelled as whole frames, not bits. Dual-OTTO and slave modes are not modelled. | Notes §4, §7. High for the TS (one OTTO). |
| OT19 | Fewer than 5 voices | ACTV 0-3 is allowed and runs ACTV+1 slots per frame. | Notes §4 says at least 5. Medium. |
| OT20 | Host memory transfers | Not in the core. The TS machine owns sound memory and the CPU path to it (Plan 3). | Notes §1. High. |

## Review Focus

1. **A host write in the middle of a frame.** Voices after the write must see it, earlier ones must not. Task 4: `otto_midframe_write_affects_later_voices_only`.
2. **Bytes of different registers interleaved** (bytes 0-2 for one register, byte 3 for another, or byte 3 alone). The result must follow OT1, never a mix with stale data that OT1 does not describe. Task 1: `otto_byte3_commits_shared_latch`.
3. **Many voices at full scale on one channel.** It must clip at the 20-bit rail, not wrap. Task 4: `otto_channel_saturates_not_wraps` (32 voices).
4. **Reading IRQV or PAR when nothing is pending, or twice.** No lost or invented interrupt, and a second PAR read before 512 slots returns 0x3FF. Task 2: `otto_irqv_read_without_pending_is_harmless`; Task 5: `otto_par_read_twice_returns_3ff`.
5. **Very few voices (ACTV below 4)** must still produce frames. Task 4: `otto_actv_below_4_still_produces_frames`.
